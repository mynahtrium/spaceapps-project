# Standup log (every 6 hours)

During the hackathon, **every 6 hours on the event clock** (hours 0, 6, 12, 18, 24, 30, 36, 42), each role's agent (or the human if no agent is in session) appends **three lines**: **Done** / **Next** / **Blocked**.

This is not a second board. Keep it short. Claim and close tasks on [BOARD.md](./BOARD.md). Put file-level detail in [AGENT_LOG.md](./AGENT_LOG.md).

If you miss a slot, add a late block at the next session and say it is late. After hour 40, one last standup at the freeze is enough.

No phone numbers, emails, addresses, or school names. First name or nickname only.

The same rule is in [AGENTS.md](../../AGENTS.md).

## Template

Copy this under a new `### Hour N` heading (create the heading once per slot):

```md
### Hour N — YYYY-MM-DD HH:MM Europe/Istanbul

**Role** (first name or nickname / agent tool)
- Done:
- Next:
- Blocked: (none, or a link to a BOARD question / handoff)
```
