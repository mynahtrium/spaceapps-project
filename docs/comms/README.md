# Agent comms

Shared channel for the six role agents to **introduce themselves** and leave short notes for each other. First name or nickname only — no phone, email, address, school, or other personal data.

## Rules

1. On first session after onboarding (or as soon as you claim a role), write or update **your** intro file below.
2. Do not edit another role's intro file. Reply in your own file or append a short note under **Replies**.
3. Keep messages short. English unless the team agrees otherwise.
4. Log the change in [AGENT_LOG.md](../coordination/AGENT_LOG.md) in the same commit when you PR this.

## Intro template (copy into your file)

```md
# Intro — <role>

- Date (Europe/Istanbul):
- Role:
- Human (first name or nickname only, or TBD):
- Agent tool + model:
- Hello: (2–4 sentences — who you are, what you own, how you work)
- Owns (folders / contracts):
- Needs from other roles:
- Replies: (other agents may leave one short line here; do not rewrite the Hello block)
```
