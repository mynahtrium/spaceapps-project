# Team profiles and onboarding interview

Doruk asked that **every agent first learn who its human is**, so coordination stays easy. On the **first session** with a human, the agent runs the interview below **before any other work**, then writes [docs/team/profiles/_TEMPLATE.md](./_TEMPLATE.md) to `docs/team/profiles/<firstname-or-nickname>.md`.

At the **start of every later session**, the agent reads **all** profile files in this folder (you may skip `_TEMPLATE.md` and this README).

Also add the GitHub username to [docs/team/ROSTER.md](../ROSTER.md) in the practice PR if that is not done yet.

## Privacy (mandatory)

Team members are **minors**. The demo and submission must not show under-18s.

**Never** collect or commit:

- Phone numbers
- Email addresses
- Home or mailing addresses
- School names
- Photos, videos, voices, or likenesses
- Full legal / family names, ages, ID numbers, or other personal data

Use a **first name or nickname only**. GitHub username on the roster is enough for git identity. If a human starts to volunteer a school name or phone number, stop them and do not write it down.

## Interview script (English / Türkçe)

Ask these in the language they prefer. You may say both. Wait for each answer. If they skip a question, leave the field blank rather than guessing.

1. **Name** — What first name or nickname should the team use for you? / Takım sana hangi ad veya takma adla seslensin? *(No surname. Soyadı yazma.)*
2. **Role** — Which role on [docs/team/ROSTER.md](../ROSTER.md) is yours (Backend 1 / 2 / 3, Frontend 1, Tester 1 / 2)? / [Kadrodaki](../ROSTER.md) rolün hangisi?
3. **Skills** — What can you already do (for example Python, git, maps, 3D, design, video)? / Şu an neleri biliyorsun (örneğin Python, git, harita, 3D, tasarım, video)?
4. **Experience** — For coding, git, maps, and 3D, are you a beginner, somewhat practised, or comfortable? / Kod, git, harita ve 3D için: yeni başlayan, biraz pratik, yoksa rahat mısın?
5. **AI tool and editor** — Which AI tool will you use (Claude, Gemini, Grok, DeepSeek) and in which editor or app? / Hangi yapay zekâ aracını ve hangi editörü / uygulamayı kullanacaksın?
6. **Operating system** — Windows, macOS, Linux, or ChromeOS? / İşletim sistemin hangisi? *(No device serial or school-laptop inventory tag. Cihaz seri no yazma.)*
7. **Explanations** — Prefer Turkish or English, and short steps, medium, or detailed? / Anlatımlar Türkçe mi İngilizce mi olsun; kısa, orta, yoksa ayrıntılı mı?
8. **Availability** — Roughly when can you work during the 48 hours (for example most of Saturday, Sunday evening)? / 48 saat içinde kabaca ne zaman çalışabilirsin? *(No home address or school timetable. Ev adresi veya okul programı yazma.)*
9. **Learning** — What do you most want to learn in this hackathon? / Bu etkinlikte en çok ne öğrenmek istiyorsun?

Then: write the profile, open a small PR, add a row to [AGENT_LOG.md](../../coordination/AGENT_LOG.md), and only then claim a board task and start other work.
