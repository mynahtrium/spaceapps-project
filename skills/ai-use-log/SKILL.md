# Log AI / SI-tool use

The [Official FAQ](https://www.spaceappschallenge.org/resources/participant-faqs/) requires each submission to describe how "SI tools" (AI tools) were used. Keep the short disclosure log in [docs/AI_USE.md](../../docs/AI_USE.md). Everyone adds their own AI_USE rows when the tool or purpose is new. The old detailed agent log (until 15 November 2026) is in [docs/AI_USE_LOG.md](../../docs/AI_USE_LOG.md) as source material for the submission paragraph.

## When to log

Log every substantive use: planning, documentation, code, data wrangling, UI copy, diagrams, or the demo video script. Short typo fixes can be batched. If you are unsure, log it.

## What to record

Use the table in `docs/AI_USE.md`:

| Field | Meaning |
|---|---|
| Date | Calendar date (team's local date is fine) |
| Tool | Name of the tool (for example Cursor, Grok Bot, Claude Code, ChatGPT) |
| What it was used for | Concrete task, not a vague "helped with the project" |
| What was kept / changed | Did the team keep the output, edit it, or reject it? Note any factual corrections |

## Rules

- Do not paste secrets, API keys, or personal data into AI tools or into the log.
- Do not invent citations. If a tool asserts a fact that is not in AGENTS.md or an official source, mark it **UNVERIFIED** until checked.
- The 30-second demo and submission must not include photos, video, voices, or likenesses of under-18s, including any AI-generated likenesses of under-18s.
- Before submission, turn this log into the short SI-tools description the Project Submission Guide asks for (guide expected 13 November; format **UNVERIFIED** until then).

## After you accept or reject AI output

Add a row the same day. If you later change the work substantially, add a follow-up row rather than rewriting history.
